主管 + 專員名單

每個區塊代表一位主管：填【主管信箱】【簡稱】【週次】。下方是專員表格，每列一位專員，可勾選「全技能／BBT／半天／計入成績」——這些標記會用在「⑤即時產能」報表的分組與人力計算，不影響「④報表結果」（日終報表照舊全部納入）。用「快速新增」貼上 Email/姓名清單可以一次產生多列，再逐列勾選即可，不用一個一個手動輸入。

即時產能

一天可產出多次（各時段各跑一次），依「全技能／非全技能」分組，各主管並排呈現。只計算「計入成績」有勾選、且當時段已有 Call 或 Chat 產能的專員；半天的人在平均產能計算時人力只算 0.5。按下產出時，「報表時間」會自動蓋上當下時間，不用手動輸入。

產能儀表板

依「④報表結果」同一批資料，依總產能（Call+Chat）排名，分成全部/全技能/單技能三欄，畫面排版做好看方便您直接截圖。日期取自④頁的「報表日期」欄位。

關於這個工具

TW 客服團隊績效工具，把上傳明細、算指標、產報表這件事整合成一個網頁流程，取代原本手動整理 Excel 的方式。所有上傳的檔案跟計算結果只存在您自己的瀏覽器裡，不會上傳到任何伺服器。

建議操作順序

📤 上傳資料：拖曳或選擇四份明細檔（Internet Call / Chat Data / Status Log / Hourly Activity），系統會自動判斷檔案類型。
🔗 欄位對應：確認每份檔案的欄位有沒有對到正確位置，通常只需要第一次設定，之後上傳同結構的檔案會自動套用。
👥 專員名單：設定主管、簡稱、週次，以及底下的專員名單（Email、姓名、全技能/BBT/半天/計入成績），可以匯出/匯入 JSON 檔跟其他人共用設定。
📊 日報表：產出完整的每日績效報表，可匯出 Excel 或 HTML。
⚡ 即時產能：一天可產出多次，依全技能/非全技能分組顯示當下產能。
🏆 產能儀表板：依總產能排名，並自動產生可貼到 SeaTalk 的公告文字。

資料儲存說明

專員名單、欄位對應設定、SeaTalk 提醒事項、深色模式偏好，都存在您瀏覽器的本機儲存空間裡，換一台電腦或清除瀏覽器資料就需要重新設定（可以用「匯出名單」先備份）。上傳的明細檔案、算出來的報表結果，都只在當次瀏覽時使用，重新整理頁面就會清空，不會留存。
